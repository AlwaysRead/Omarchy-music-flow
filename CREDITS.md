# Credits and provenance

This is a customized fork of [Omarchy Music Flow](https://github.com/Clifford-Baidoo/Omarchy-music-flow), not the original upstream release.

- **Clifford Baidoo / Clifford Kingsley Baidoo** — original Music Flow author and upstream maintainer. The original MIT copyright notice remains unchanged in [LICENSE](LICENSE).
- **DevInBlack001 and Abdullah Armiyao** — upstream contributions recorded in the inherited Git history, including playback detection, player selection, installer cleanup, and audio monitoring fixes.
- **Omarchy contributors** — the desktop shell, shared UI components, and original `omarchy.media` widget from which this plugin was derived. See [Omarchy](https://github.com/basecamp/omarchy).
- **CAVA contributors** — the external audio spectrum analyzer used by this fork. See [CAVA](https://github.com/karlstav/cava). CAVA is a separate runtime dependency and is not bundled here.

This fork adds the current six-mode CAVA visualizer, attack/release smoothing, saved display preferences, artwork fallback, and revised floating-player interface. Inherited commits and author attribution are preserved in Git history. No ownership of the upstream work is claimed.
